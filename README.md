# Sales and Profit Performance Dashboard (Excel)
An interactive Business Intelligence Dashboard built in Microsoft Excel to analyze
sales, profit, customer segments, regional performance, and product category profitability.

## Dataset used
- <a href="https://github.com/aagaz06/Sales-Profit-Dashboard/blob/main/S1-SuperStoreUS-2015.xlsx">S1-SuperStoreUS-2015</a>

## Project Overview
This project transforms raw sales data into actionable business insights using Excel-based
analytics and dashboarding techniques. The dashboard enables users to monitor key performance indicators (KPIs),
track monthly trends, evaluate regional and category performance, and identify top-performing customers.

- Dashboard Interaction <a href="https://github.com/aagaz06/Sales-Profit-Dashboard/blob/main/Sales%20%26%20Profit%20Dashboard.xlsx">View Dashboard</a>

## Key Features
- Interactive dashboard with dynamic slicers and timeline filters
- KPI cards for Total Sales, Total Profit, Orders, Average Order Value, and Profit Margin
- Month-wise Profit Trend Analysis
- Regional Sales Distribution Analysis
- Customer Segment Performance Analysis
- Profit by Region and Product Category Analysis
- Top 5 Customers by Profit
- Automated Key Insights and Business Recommendations
- Dynamic calculations using formulas and Pivot Tables
